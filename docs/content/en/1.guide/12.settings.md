## Appearance

Theme, primary color, background color and rounding. See [Theme](/en/guide/theme) for all options.

## Language

Finapp supports two languages:

- **English** (en)
- **Russian** (ru)

The app detects your browser language automatically on first visit. Language is also available from the account menu and on the login page.

Your language choice is synced to the server - it will be restored on any device you log in to.

## Notifications

Enable push notifications for this device. The browser asks for permission the first time you turn the switch on; if you declined earlier, allow notifications in the browser's site settings and try again.

On iPhone and iPad, notifications only work after the app is [added to the home screen](/en/guide/installation#iphone).

## Base Currency

Set your base currency for unified balance totals across all wallets. All wallet balances are automatically converted to this currency using daily exchange rates. Synced to the server like the language.

Default: **USD**.

## Demo Mode

Try Finapp without creating an account: tap **Open Demo** on the login page. Demo mode generates sample data so you can explore all features:

- About 900 randomly generated transactions over the last 2 years
- 32 categories with parent-child hierarchy
- 8 wallets in different currencies (including a credit card and an archived wallet)
- All features work (create, edit, delete, statistics, saved views)
- Data is stored locally in your browser

Actions:
- **Update demo data** (Settings) - regenerate all sample data
- **Exit demo mode** (account menu) - return to the login page

## Exchange Rates

Exchange rates are fetched once a day from [Open Exchange Rates](https://openexchangerates.org) and Coinbase, and synced to every device.

### Currencies Page

The **Currencies** page (`/currencies`) shows every currency with its rate relative to the base currency:

- **Used** - the currencies of your wallets, base currency first.
- **Fiat** / **Crypto** tabs - all other currencies with a known rate.
- **Search** by code or name filters both lists.

Right-click (long-press on mobile) a currency and choose **Set as base currency** to switch. All rates are recalculated relative to the new base.

Rates are cached locally - the page works offline using the last downloaded data.

## Data Deletion

**Delete my data** permanently removes all wallets, categories, transactions and saved views from the server. Requires confirmation. Cannot be undone.

## Account

Shows the signed-in account and its sync state (offline, unsynced changes, upload errors), with the **Logout** button. See [Authentication](/en/guide/auth#sign-out).
