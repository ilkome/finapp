## Обзор

Кошельки - это ваши финансовые счета: банковские счета, наличные, карты или любое другое место, где хранятся деньги.

## Типы кошельков

У каждого кошелька есть тип, который определяет его поведение:

- **Наличные** - физические деньги
- **Безналичные** - банковские счета и электронные платёжные системы
- **Кредитные** - кредитные карты (с поддержкой кредитного лимита)
- **Вклады** - сберегательные вклады
- **Крипто** - криптовалютные кошельки
- **Долги** - займы и долги

## Создание кошелька

Перейдите в **Кошельки** → **+**. Заполните:

- **Название** - обязательное, отображается везде
- **Валюта** - открывает окно с поиском по 180+ фиатным и криптовалютам. Уже используемые валюты показываются первыми. Поиск по коду или названию. По умолчанию: **USD**
- **Цвет** - палитра с полем для своего цвета и предпросмотром иконки кошелька
- **Описание** - необязательные заметки, показываются на странице кошелька
- **Тип** - наличные (по умолчанию), безналичные, кредитные, крипто, вклады, долги

### Дополнительные настройки

| Настройка | Эффект |
|-----------|--------|
| Кредитный лимит | Только для типа **кредитные**. Страница кошелька и статистика показывают долг, доступный остаток и лимит |
| Доступные для снятия | Помечает кошелёк как деньги, которые реально можно снять. Учитывается в строках **Доступные для снятия** и **Останется после кредитов** |
| Не считать в общем балансе | Баланс не входит во **Всего** и в строки по типам |
| Архивный | Скрыт из списка и исключён из всех строк статистики, пока не включена соответствующая опция |

## Список кошельков

### Группировка

Вкладки над списком переключают плоский **Список**, группировку по **Типу** и по **Валютам**. При группировке справа появляются две кнопки:

- **Группировка** - вложить вторую группировку внутрь (валюта → тип или тип → валюта). Каждая группа и подгруппа сворачивается независимо.
- **Папки** - развернуть или свернуть все группы разом.

Заголовок группы показывает её сумму в базовой валюте (для валютных групп - ещё и в родной валюте). Включите **Показывать количество в группах** в меню, чтобы видеть число кошельков в каждой группе.

### Фильтр по валюте

Если кошельки в нескольких валютах, над статистикой появляется полоска чипов (Все / RUB / USD / ...). Выберите валюту, чтобы ограничить и список, и статистику. Полоска скрыта при группировке по валютам.

### Статистика

Блок статистики показывает суммы в базовой валюте, по строке на каждый срез:

| Строка | Что показывает |
|--------|----------------|
| Всего | Все кошельки, кроме кредитных и исключённых из общего баланса |
| Доступные для снятия | Кошельки с включённой опцией **Доступные для снятия** |
| Останется после кредитов | Доступные для снятия минус долг по кредитным картам. Показывается, только когда есть и те, и другие |
| Не учитываемые в общем балансе | Кошельки с опцией **Не считать в общем балансе** |
| Архивные | Архивные кошельки |
| Наличные / Безналичные / Вклады / Кредитные / Крипто / Долги | Сумма по типу. У кредитных дополнительно показан использованный и общий лимит |

Строки с нулевой суммой скрыты. Нажмите на строку, чтобы отфильтровать список по этому срезу; нажмите **Всего**, чтобы вернуться. Если фильтр опустел (например, после смены валюты), список автоматически возвращается к **Всего**.

Две строки - **Всего** и **Останется после кредитов** - по умолчанию **закреплены** и выводятся крупными карточками над списком. Откройте **⋮ → Статистика**, чтобы:

- закреплять и откреплять строки, перетаскивать закреплённые карточки,
- скрывать строки из списка и менять порядок оставшихся,
- прочитать, что означает каждая строка (кнопка **i**).

Закреплённые, скрытые и порядок строк запоминаются отдельно для каждого режима группировки.

### Меню

Кнопка **⋮** (появляется, когда кошельков больше одного) открывает:

- **Сортировать кошельки** - перетаскивание. Порядок синхронизируется с другими устройствами и используется везде: в боковой панели, селекторах и на дашборде.
- **Статистика** - панель строк, описанная выше.
- **Показывать архивные кошельки** - включить архивные в список.
- **Учитывать архивные в статистике** и **Учитывать не входящие в баланс** - считать эти кошельки в строках по типам и в общей сумме.
- **Показывать количество в группах** - число кошельков рядом с заголовком группы.

## Страница кошелька

Нажмите на кошелёк, чтобы открыть его страницу. На ней баланс (у кредитных с лимитом - **Долг**, **Доступно** и **Лимит**), описание и та же статистика, что на [Дашборде](/ru/guide/statistics), отфильтрованная по этому кошельку. Блоки **Баланс кошелька** и **Описание кошелька** можно скрыть в настройках вида.

В меню **⋮**: **Редактировать** открывает форму кошелька, **Удалить** удаляет кошелёк и все его транзакции. Диалог подтверждения показывает, сколько транзакций будет затронуто.

Боковая панель на десктопе показывает все кошельки с балансами - нажмите, чтобы открыть страницу; по правому клику доступны **Открыть**, **Редактировать** и **Удалить**.

## Начальный баланс

Новые кошельки создаются с нулевым балансом. Чтобы задать начальный баланс, создайте транзакцию с категорией **Корректировка** на нужную сумму. Корректировки не влияют на статистику, поэтому отчёты остаются чистыми. Подробнее в разделе [Транзакции - Корректировки](/ru/guide/transactions#корректировки).

## Расчёт баланса

Баланс кошелька - это сумма всех транзакций: доходы увеличивают баланс, расходы уменьшают. Переводы между кошельками корректируют балансы обоих кошельков.

## Мультивалютность

У каждого кошелька своя валюта. Финапка ежедневно загружает курсы и конвертирует все балансы в базовую валюту для единых итогов. См. [Настройки - Курсы валют](/ru/guide/settings#курсы-валют).
